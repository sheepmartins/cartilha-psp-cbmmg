# Fontes

Os títulos usam **Creato Display**, que é comercial e por isso não é
distribuída aqui. O `style.css` já tem as regras `@font-face` apontando para
esta pasta: basta soltar os arquivos abaixo e os títulos passam a usar a fonte
original.

```
CreatoDisplay-Regular.woff2
CreatoDisplay-Bold.woff2
CreatoDisplay-Black.woff2
```

Enquanto não estiverem aqui, o fallback é **Figtree** (Google Fonts).
